📦 Add Bitbucket Repository

Paste the repository page link to fill in the project key and repository.
Token is encrypted before storage. It will not be displayed again.
To add several (or all) repositories: leave Repository empty and click Browse repositories. On a company server, leave the project key empty to list every repository you can access.

📋 Add Jira Project

Company Jira (e.g. jira.company.com): your avatar > Profile > Personal Access Tokens > Create token, and leave the email empty. Jira Cloud: email + API token from id.atlassian.com > Security. Token is encrypted before storage. It will not be displayed again.

📘 Add Confluence Space

Every current page in the space is indexed, not just one page.
Company Confluence: your avatar > Settings / Profile > Personal Access Tokens > Create token. Confluence Cloud: email + API token from id.atlassian.com > Security. Encrypted before storage.
